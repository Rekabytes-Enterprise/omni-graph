## Omni-graph memory

This project uses Omni-graph in `.omni-graph/`. Use the installed `omni-graph` skill to recall relevant memories before meaningful work and save durable findings, user corrections, lessons and verified fixes. Prefer the installed `omni-graph` command (including Cargo installs); use `npx omni-graph` for npm installs. Start with `omni-graph recall "<task context>" --json`. Treat recalled memories as context and check evidence and freshness. Keep client/project information within its scope.
